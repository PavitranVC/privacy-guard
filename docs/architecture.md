# Technical Architecture Specification (v5 Locked)

## 1. Dual-Tier On-Device Static & ML Triage Engine
- **Cache & Poison-Pill Guard:** Room `scan_cache(pkg, versionCode, lastUpdateTime, totalApkBytes, featuresBlob)` + `scan_failed(pkg, versionCode, crashCount)` (quarantine after 2 `:scan` crashes).
- **Tier 1A — Instant Manifest Scan (Sync, Main Process, under 5 ms):**
  - Query installed apps via `getPackageInfo(pkg, GET_SERVICES | GET_RECEIVERS | GET_PROVIDERS | GET_PERMISSIONS)` (omitting `GET_ACTIVITIES` to avoid large IPC payloads). Use `pxb.android:axml` only for uninstalled APKs or intent-filter inspection.
  - Match manifest component class names (immune to R8 renaming) against Ed25519-verified offline Exodus Privacy rules (pinned SPKI: `MCowBQYDK2VwAyEAgCYpThvpyHUz6FbXD+eFlCHG818ajDs/UOcGH6HV6ew=`), alongside dangerous permissions (`BIND_ACCESSIBILITY_SERVICE`, `READ_SMS`, `SYSTEM_ALERT_WINDOW`, `SCHEDULE_EXACT_ALARM`) and `BOOT_COMPLETED` receivers.
- **Tier 1B — C++17 JNI `mmap` Scanner & Flat-Array LightGBM (Isolated `android:process=":scan"`):**
  - **Process Isolation:** Guard `Application.onCreate()` on `Application.getProcessName()`. Keep Room, WorkManager, and Shizuku strictly in the main process; `:scan` communicates exclusively over AIDL/Messenger (receiving `ParcelFileDescriptor`s from main process if Shizuku FD fallback is needed) and exits when idle.
  - **ZIP & Native I/O:** Parse ZIP central directories in Kotlin via `java.util.zip.ZipFile` (handles ZIP64 and data descriptors). Pass `(fd, dataOffset, compressedSize, uncompressedSize, method)` to C++. For Stored entries, `mmap(..., MAP_PRIVATE, ...)` page-aligned down via `sysconf(_SC_PAGESIZE)` with `madvise(MADV_SEQUENTIAL)` and immediate `munmap`. For Deflated entries, compute data start from local header name/extra lengths and inflate via raw `inflateInit2(&s, -MAX_WBITS)` with a strict 32 MB output cap. Return a single `FloatArray` via `SetFloatArrayRegion`.
  - **Feature Extraction:** Union `string_ids`, `type_ids`, and `method_ids` across all `classes*.dex`; flag cross-DEX or unresolved class descriptors (`DexClassLoader`/`InMemoryDexClassLoader`). Exclude `Landroidx/`, `Lkotlin/`, `Lkotlinx/` before computing short-name ratios and 64 KB sampled entropy; normalize by class count. Single-pass Aho-Corasick (16 MB/file cap, 1 MB windows) over ELF `.so` imports (`dlsym`, `ptrace`, `mprotect`) + endpoints, Flutter `assets/flutter_assets/NOTICES.Z` (`inflateInit2`) + `io.flutter.plugins.*`, React Native Hermes (`0x1F1903C103BC1FC6`), and Unity `global-metadata.dat` (`0xFAB11BAF`).
  - **C++ LightGBM + Isotonic Evaluator:** ~100-line C++ evaluator reading Ed25519-verified flat arrays (`feature`, `threshold`, `left`, `right`, `leaf`) from `filesDir` (fallback to bundled asset verified with pinned SPKI: `MCowBQYDK2VwAyEAgCYpThvpyHUz6FbXD+eFlCHG818ajDs/UOcGH6HV6ew=`). Evaluate interleaved multiclass trees (`tree_idx % 4`) in `double` honoring `default_left`, apply softmax, then per-class piecewise-linear isotonic calibration and renormalization (`confidence < 0.90` queues OSINT). Verified in CI against Python `predict_proba` on 1,000 vectors (`tolerance 1e-6`).

## 2. Active VPN & Private DNS Shield Telemetry (No `VpnService`)
- **Passive Check:** `ConnectivityManager.registerNetworkCallback` requiring `TRANSPORT_VPN`, `NET_CAPABILITY_NOT_SUSPENDED`, default routes `0.0.0.0/0` and `::/0`, `LinkProperties.isPrivateDnsActive()` + `getPrivateDnsServerName()`, and `Settings.Secure.getInt(cr, "always_on_vpn_lockdown", 0)`.
- **Active Dual-Socket Probe:** Bind sockets to VPN `Network` and `nc.underlyingNetworks.firstOrNull()` (`network.bindSocket()`), querying `https://1.1.1.1/cdn-cgi/trace`. Timeout on VPN = Stalled Tunnel; equal egress IPs = Tunnel Leak; verify `warp=on` when WARP is active.

## 3. Deterministic OSINT & Cryptographic Verification Engine
- Single serialized `WorkManager` drain worker (`NetworkType.UNMETERED`, `setRequiresBatteryNotLow(true)`), ordered by descending ML risk, enforcing per-host `next_allowed_at` + exponential backoff (30s base) + negative TTL cache + multi-day jitter.
- Hash-only VirusTotal/MalwareBazaar lookups across `base.apk` and code splits (skipping `config.*` splits, never uploading APKs). Verify direct sideloads via `signingInfo.apkContentsSigners` and whole-APK SHA-256 against F-Droid (`/api/v1/packages/<pkg>`) and GitHub Releases (`asset.digest`).
- Three-state evidence (`NO_DATA` != `CLEAN`). LLM (local LAN Ollama primary, free cloud fallback) extracts strict JSON (`kotlinx.serialization`) `(claim, source_url, evidence_type)` from stripped public text; deterministic Kotlin code computes final verdict (requires at least 2 Tier-1/2 sources for `malicious`).

## 4. Idempotent Shizuku State Machine & Crash-Safe Remediation
- **PrivilegeBackend & Shell Execution:**
  - Pluggable `PrivilegeBackend` interface (`val id: String`, `fun exec(cmd: Array<String>): ShellResult`) abstracts privileged command execution from concrete privilege providers.
  - `ShizukuBackend` (id = `"shizuku"`) delegates to a bound Shizuku `UserService` (`void destroy() = 16777114`) running under shell UID to execute allowlisted commands over AIDL. Root is a planned future backend behind an explicit user toggle (never auto-detected). Every backend must enforce the same command allowlist as `ShizukuShellService.validateCommand` before executing.
  - **Hardware Verification (Moto G54 / Android 15):** Component-level `pm enable|disable|disable-user` is denied for other packages' components at shell privilege (`SecurityException: Shell cannot change component state for ...`). Viable non-root primitives at shell privilege are:
    1. Chain 3 per-package networking isolation (`cmd connectivity set-chain3-enabled true` + `set-package-networking-enabled false <pkg>`);
    2. Background hibernation (`cmd appops set --uid <uid> RUN_ANY_IN_BACKGROUND ignore` + `am set-standby-bucket <pkg> restricted`);
    3. Package-level disable (`pm disable-user --user <id> <pkg>`);
    4. Runtime permission grant/revoke (`pm grant|revoke`).
  - **UI Principle (Reported vs Enforced):** AppOps query results represent the REPORTED mode in the system server only; actual enforcement/blocking of operations (e.g., clipboard read, notifications) remains unverified. The UI must explicitly distinguish "reported state" from "verified enforced state".
- **Room Tables (WAL, `synchronous=NORMAL`):**
  - `reconcile_request(pkg TEXT PRIMARY KEY, requestedAt INTEGER)` (`INSERT OR IGNORE`), fed by `PackageManager.getChangedPackages(lastSeq)`, `Shizuku.addBinderReceivedListener`, and `ACTION_POWER_SAVE_WHITELIST_CHANGED`.
  - `policy_op(id, pkg, versionCode, lastUpdateTime, op, target, desired, observed, status, errClass, attempts, nextAt, gen, snapshot)` where `status` in `{PENDING, APPLYING, APPLIED, DRIFT, FAILED_TRANSIENT, FAILED_PERMANENT, ROLLED_BACK_UNSAFE}`, indexed on `(pkg, versionCode)` and `status`.
  - `capability(op TEXT PRIMARY KEY, supported INTEGER, buildFingerprint TEXT, probedAt INTEGER)`.
- **Executor & Safe-List:** Single `Dispatchers.IO.limitedParallelism(1)` executor; optimistic locking (`WHERE id = :id AND gen = :gen`); re-verify live `(versionCode, lastUpdateTime)` before mutating. If component mutations are attempted, mutate only `Service` and `Receiver` components declared in the target app's manifest via `COMPONENT_ENABLED_STATE_DISABLED_USER` (`DONT_KILL_APP`), protecting `com.google.android.gms`, `com.android.vending`, `com.android.gsf`, `InitializationProvider`, `FirebaseInitProvider`, `FirebaseMessagingService`, `FirebaseInstanceIdReceiver`, `ComponentDiscoveryService`, `GoogleApiActivity`, and OAuth sign-in activities. Check `getHistoricalProcessExitReasons` (`CRASH`, `CRASH_NATIVE`) 60s post-apply and auto-restore `snapshot` on new crashes. Use `am kill --user 0 <pkg>` (never `am force-stop`).
- **Wi-Fi Isolation Ladder (UID `userId * 100000 + appId`):** (1) `cmd connectivity set-chain3-enabled true` + `set-package-networking-enabled false <pkg>`; (2) `IConnectivityManager` binder firewall chain 9 fallback; (3) `cmd appops set --uid <uid> RUN_ANY_IN_BACKGROUND ignore` + `am set-standby-bucket <pkg> restricted`; (4) honest UI status `"UNISOLATABLE_ON_WIFI"`.
